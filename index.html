See wheels on your car

Upload a side photo of your own car (or try the sample), pick a wheel, then change the wheel diameter and tire size. The preview updates instantly, right in your browser.

How it works

1 · Photo

Upload or take a side-profile photo. Wheels are found automatically, and you can drag or resize each one. Photos never leave the device.

2 · Wheel

Browse the shop's own catalog, filter by finish, search, and tap to try. Use “Spin” to animate it and “Before / after” to compare.

3 · Size & tire

Pick 16–26" wheels. Tire profile can follow automatically to keep the same overall height, or you can set width and profile yourself. It shows the tire's overall diameter and sidewall height.

Add it to any wheel or tire shop website

You only need one <div> and one <script>. It has no backend and no dependencies, and the widget runs in a Shadow DOM so it won't clash with the site's CSS.

Catalog formats

data-catalog takes (a) a JSON file {"wheels":[{"name","finish","url","face","thumb","price","diameters_listed"}]}, (b) a plain array, or (c) a Shopify /products.json URL. With Shopify, wheel products are picked out automatically, and their photos are cut out and flattened in the browser.

Shopify install

In Online Store → Themes → Customize, add a Custom Liquid section to a page and paste the snippet. Set data-catalog="/products.json?limit=250" (same-origin, so no CORS setup is needed). The same snippet works as a theme app extension block.

Other sites

For WordPress/WooCommerce, Wix, Squarespace, or a custom/ColdFusion site, paste it into an HTML or embed block. Host catalog.json and the wheel PNGs on the same domain, or allow CORS.

Theming

data-brand-color, data-logo, data-shop-name, data-theme="dark|light", data-phone, data-cta-url (a quote form, mailto:, or tel:), data-cta-label, data-sample-car, data-default-tire.

JavaScript API

WheelVisualizer.mount('#el', {catalog:'…', brandColor:'#c8102e'}). Events on the host element: wv:catalog, wv:wheel, wv:detected, which you can use for analytics.

Disclaimer

The preview is visual only. Fitment isn't guaranteed and must be confirmed with the shop. The widget shows only the sizes the shop lists for each wheel.
